# Campus Connect Rework — Implementation Plan

## Goal
Rework Campus Connect from Neo4j + custom auth to Supabase (PostgreSQL + Auth + Storage + Realtime).

## Design System
**DESIGN.md is the single source of truth for all frontend design.** Meta/Facebook design system. Colors, typography, spacing, components, responsive behavior. `tailwind.config.ts` mirrors these tokens exactly. Every UI component must follow DESIGN.md.

## Status
- Phase 0 (Cleanup): ✅ Done
- Phase 1 (Foundation): ⬜ Next
- Phase 2-6: ⬜ Planned

## Key Decisions
- **Supabase** replaces Neo4j, Express.js, custom auth, Upstash Redis
- **PostgreSQL** instead of graph database
- **Free tier**优先 — Supabase free tier covers dev
- **Keep all UI** — 21 Radix components, TipTap editor, all feature pages
- **Rewrite all backend** — DB layer, API routes, auth
- **DESIGN.md** = design bible for all frontend work
