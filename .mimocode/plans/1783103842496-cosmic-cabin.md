# Campus Connect — Full Rework Plan

## Vision
A social media platform for college students — a fusion of **WhatsApp** (messaging), **Facebook** (feed, communities, events), **Discord** (groups, real-time), and **LinkedIn** (professional profiles, jobs, research).

---

## PHASE 0: CLEANUP & DOCUMENTATION (Do First)

### Step 1: Delete Unrequired Files/Directories

**DELETE entirely:**
- `apps/api/` — redundant Express.js server (auth logic moves to Next.js API routes)

- `src/server/db/client.ts` — Neo4j helpers (replaced by Supabase client)

- `src/lib/auth/session.ts` — custom HMAC tokens (replaced by Supabase Auth)
- `src/lib/auth/server.ts` — custom server auth (replaced by Supabase)
- `src/lib/rate-limit.ts` — custom rate limiter (Supabase RLS replaces this)
- `src/lib/rate-limit.test.ts` — tests for removed rate limiter
- `src/middleware.test.ts` — tests for old middleware
- `src/app/(dashboard)/discover/page.tsx` — just redirects to /explore
- `src/app/(dashboard)/layout.responsive.test.tsx` — test for removed responsive layout
- `docs/neo4j-redis-migration.md` — outdated migration doc
- `MONOREPO_SETUP.md` — outdated monorepo doc
- `README_MONOREPO.md` — outdated monorepo doc
- `src/types/sentry-nextjs.d.ts` — may not be needed
- Convex compatibility shims in `src/lib/api.ts` (`ConvexReactClient`, `ConvexProvider`, `useConvexAuth`)

**KEEP but flag for rewrite:**
- `src/lib/api.ts` — keep structure, rewrite types (replace `any` with proper types)
- `src/lib/auth/client.tsx` — keep UI components, rewrite to use Supabase
